# Участие в разработке MIRA-TV

Спасибо за интерес к MIRA-TV.

Этот файл описывает базовые правила работы с исходным кодом проекта.

## Требования для разработки

Нужны:

- Node.js 24 или новее;
- npm;
- Docker с Docker Compose;
- Git.

Для браузерных тестов используется Chromium через Playwright.

## Установка зависимостей

```bash
npm ci
```

## Проверка JavaScript

```bash
npm run build
```

Команда проверяет синтаксис JavaScript-файлов проекта.

## Обычные тесты

```bash
npm test
```

## Браузерные тесты

```bash
npm run test:browser
```

Для них требуется установленный браузер Playwright и тестовое окружение приложения.

## Быстрая общая проверка

```bash
npm run check
```

## Docker

Проверить итоговую конфигурацию:

```bash
docker compose config --quiet
```

Собрать и запустить проект:

```bash
docker compose up -d --build
```

## Перед отправкой изменения

Убедитесь, что:

- код относится к заявленной задаче;
- не добавлена лишняя фоновая работа на телевизоре;
- существующие функции не дублируются новым параллельным механизмом;
- новые настройки имеют понятное назначение;
- документация обновлена, если изменилось поведение пользователя или установка;
- `npm run check` проходит;
- относящиеся к изменению браузерные тесты проходят;
- `docker compose config --quiet` не сообщает ошибок.

## Производительность телевизора

MIRA-TV рассчитана на устройства с ограниченными ресурсами.

Не добавляйте постоянный сетевой опрос, повторное создание неизменившегося меню или непрерывные JavaScript-циклы без необходимости.

Если экран статичен, код телевизора должен в основном бездействовать.

Подробнее: [docs/PERFORMANCE.md](docs/PERFORMANCE.md).

## Совместимость документации

Публичная документация должна быть понятна человеку, который не знает внутреннюю историю проекта.

По возможности используйте обычные слова вместо внутренних названий классов, временных архитектурных терминов и названий этапов разработки.

## Секреты

Никогда не добавляйте в репозиторий:

- рабочий `.env`;
- пароли;
- токены;
- cookie;
- приватные ключи;
- реальные секреты базы данных или сессий.
