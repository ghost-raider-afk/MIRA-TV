# MIRA-TV

**MIRA-TV** — система централизованного управления цифровыми меню для телевизоров торговых точек. Меню, цены, оформление и доступ к экранам настраиваются в веб-панели; на телевизорах работает локально устойчивый браузерный Player.

**Текущая стабильная версия: [v1.18.26](https://github.com/ghost-raider-afk/MIRA-TV/releases/tag/v1.18.26).** Список новых версий — [GitHub Releases](https://github.com/ghost-raider-afk/MIRA-TV/releases). Канонический номер версии хранится в `package.json`.

## Возможности

- Торговые точки, отдельные экраны и общий каталог товаров, включая характеристики и несколько вариантов цен.
- Компактный Scene Editor: фон, таблица меню, текст, логотипы, изображения и погода.
- Три системные темы меню («Премиальная», «Меловая», «Брендовая премиальная») и «Конструктор темы» с сохранением пользовательского оформления.
- Live-погода с получением данных через сервер; часы и текст в тематическом utility slot.
- Подключение телевизоров по QR-коду или короткому коду, TV-сеть и диагностика подключений.
- Раздел **«Мониторинг»**: состояние телевизоров, графики производительности и время работы.
- Роли администратора и менеджера, распределение доступа к торговым точкам.
- CRM-заявки на изменения цен, свойств, состава меню и каталога, история решений, журнал событий и уведомления только по заявкам.
- Local-first Player: после первого успешного показа сохраняются рабочая сцена и необходимые ресурсы; при временной потере сервера/сети показ продолжается.
- Обновление только изменившихся компонентов и безопасное переключение на новую сцену после подготовки файлов.

## Показ на телевизоре

~~~text
Администратор / менеджер → Сервер MIRA-TV → HTTPS + WebSocket → TV Player
                                    │                         │
                               PostgreSQL             Локальный LKG
                                                              │
                                                 Статическая сцена + SVG
~~~

Рабочий режим — **статический live-render**. `PlayerSceneRenderer` использует один render model/layout в Scene Editor, Preview и телевизоре. Таблица создаётся через `FlatMenuRenderer` как векторный SVG, обычные элементы — через `SceneElementRenderer`. Preview отличается от TV только масштабом канонического полотна.

**Видео как элемент сцены, Video Mode, Render Agent и runtime плейлиста сцен не поддерживаются действующим Player.** Для статического меню постоянный цикл перерисовки не требуется. Погода может получать новые данные, не превращая сцену в непрерывную анимацию.

## Технологии

| Компонент | Технология |
| --- | --- |
| Backend / API | Node.js 24+, Express 5 |
| Данные | PostgreSQL 17 |
| Интерфейс / TV Player | Нативный JavaScript, HTML, CSS, SVG |
| Доставка / HTTPS | Docker Compose, Traefik 3 (file provider) |
| Тесты | Node.js test runner, Playwright, Docker/DB/visual regression |

Снаружи открыты порты `80` и `443`. Для проверки готовности предусмотрен `/readyz`. Пользовательские assets хранятся на сервере в постоянном Docker volume; TV не зависит от внешнего CDN для показа сцены.

## Установка

Нужны Ubuntu, домен с DNS-записью на сервер, доступ `root`/`sudo`, открытые порты `80`/`443` и интернет для установки.

~~~bash
bash <(curl -Ls https://raw.githubusercontent.com/ghost-raider-afk/MIRA-TV/main/mira-tv.sh)
~~~

Выберите «Установить». После установки меню открывается командой:

~~~bash
mira-tv
~~~

Рабочий каталог — `/opt/MIRA-TV`, локальная конфигурация — `/opt/MIRA-TV/.env`. Пароли и ключи из `.env` не публикуются.

См. [установку и обновление](docs/INSTALLATION.md) и [настройки](docs/CONFIGURATION.md).
