# MIRA-TV

**MIRA-TV 1.0.2** — веб-приложение для управления цифровыми меню и показа их на телевизорах.

Система подходит для магазинов, кафе, баров, ресторанов и других точек, где содержимое экранов нужно менять из одного места.

## Что умеет MIRA-TV

- создавать торговые точки и подключать к ним телевизоры;
- вести общий каталог товаров и тары;
- создавать меню и настраивать внешний вид каждого экрана;
- добавлять фон, изображения, видео, текст и анимацию;
- подключать телевизор по QR-коду или короткому коду;
- обновлять экран после изменений без постоянной перезагрузки страницы;
- продолжать показ последнего рабочего меню при временной потере связи с сервером;
- управлять пользователями, настройками сайта и журналом событий;
- запускаться и обновляться стандартными командами Docker Compose.

## Как это работает

MIRA-TV состоит из серверной части и страницы плеера, открытой на телевизоре.

```text
Панель управления
       ↓
     Сервер
       ↓
    Интернет
       ↓
Телевизор с MIRA-TV Player
```

Администратор меняет меню в браузере. Сервер сохраняет изменения и сообщает нужному телевизору, что появилась новая версия экрана. Телевизор получает только необходимые данные и продолжает показывать меню локально.

Если связь временно пропала, уже загруженное рабочее меню остаётся на экране.

## Основные компоненты

- **Node.js** — сервер приложения и панель управления;
- **PostgreSQL** — база данных;
- **Traefik** — принимает защищённые HTTPS-соединения и получает сертификаты;
- **Docker Compose** — запускает все серверные компоненты;
- **браузер телевизора** — показывает меню, изображения, видео и анимацию.

Дополнительный файловый сервер не требуется. Меню, изображения и видео передаются через обычное защищённое HTTPS-соединение.

## Требования

Для серверной установки нужны:

- VPS или сервер с Ubuntu;
- доменное имя, направленное на сервер;
- открытые порты `80` и `443`;
- доступ `root` или `sudo`;
- доступ сервера в интернет для загрузки исходного кода и Docker-образов.

Docker устанавливается автоматически, если его ещё нет.

## Быстрая установка

Вставьте одну команду:

```bash
bash <(curl -Ls https://raw.githubusercontent.com/ghost-raider-afk/MIRA-TV/main/mira-tv.sh)
```

Сразу откроется меню установщика. Выберите **`1) Установить`**.

Если команда запущена не от `root`, скрипт сам запросит права через `sudo` только после выбора операции, которой они нужны.

После установки рабочие файлы находятся в:

```text
/opt/MIRA-TV
```

Настройки находятся в:

```text
/opt/MIRA-TV/.env
```

Подробная инструкция: [docs/INSTALLATION.md](docs/INSTALLATION.md).

## Обычное управление через Docker Compose

Вся серверная часть MIRA-TV запускается одним `compose.yaml`.

```bash
cd /opt/MIRA-TV
sudo docker compose up -d
```

Полезные команды:

```bash
sudo docker compose ps
sudo docker compose logs -f
sudo docker compose restart
sudo docker compose stop
sudo docker compose start
sudo docker compose down
```

После изменения исходного кода или Dockerfile:

```bash
sudo docker compose up -d --build --wait
```

Обычная команда `docker compose down` не удаляет данные базы. Удаление данных выполняется только отдельной явной командой.

## Первый запуск

После установки рекомендуется:

1. войти в панель администратора;
2. создать торговую точку;
3. добавить товары в каталог;
4. создать экран и настроить меню;
5. открыть MIRA-TV Player на телевизоре;
6. привязать телевизор по QR-коду или короткому коду;
7. проверить, что изменения меню появляются на нужном экране.

Подробнее: [docs/USAGE.md](docs/USAGE.md).

## Принцип работы на телевизоре

MIRA-TV специально устроена так, чтобы телевизор выполнял как можно меньше лишней работы.

Если содержимое экрана не менялось, статическое меню не создаётся заново. Видео воспроизводится средствами самого браузера, а невидимые анимации и видео приостанавливаются. Уже загруженные файлы используются повторно.

Это особенно важно для телевизоров со сравнительно слабым процессором и небольшим объёмом памяти.
