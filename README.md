# MIRA-TV

Ветка `prototype` — экспериментальная линия новой архитектуры MIRA-TV. Она создаётся отдельно от стабильной `main` и не является релизом для рабочего сервера.

Текущая стабильная версия продукта в `main` — **1.0.3**. Ветка `prototype` используется для полной переработки модели создания и управления контентом.

## Новая концепция

MIRA-TV развивается из редактора меню конкретного телевизора в универсальную платформу визуальных сцен.

Главный пользовательский поток:

```text
Каталог
   ↓
Сцены
   ↓
Конструктор сцены
   ↓
Несколько слайдов и свободные элементы
   ↓
Сохранить как шаблон
   ↓
Торговая точка
   ↓
TV / горизонтальная группа TV
   ↓
Режим показа
   ↓
MIRA-TV Player
```

Сцена создаётся независимо от физического телевизора. В неё можно добавлять фон, таблицы, текст, изображения, логотип, видео, часы, погоду, фигуры и другие информеры. Элементы свободно размещаются на Canvas, получают эффекты и анимацию. Одна сцена может содержать несколько слайдов.

Для нескольких телевизоров предусмотрен единый широкоформатный Canvas. Поддерживается только горизонтальный ряд TV слева направо.

## Главные принципы

- Canvas является центром работы пользователя;
- дизайн отделён от эксплуатации торговой точки;
- Preview и TV Player должны использовать один Scene Renderer;
- сложность раскрывается постепенно, а частые действия доступны сразу;
- новый элемент должен давать хороший результат с разумными настройками по умолчанию;
- изменение одного объекта не должно без причины пересоздавать всю сцену;
- TV Player должен выполнять минимум лишней работы;
- PostgreSQL, медиатека и рабочие данные должны иметь согласованный lifecycle;
- AI не входит в текущий этап. Сначала ручной конструктор должен быть доведён до безупречного состояния.

## Что уже есть в `prototype`

Первый интерактивный каркас позволяет:

- открыть библиотеку сцен;
- создать сцену отдельно от торговой точки;
- использовать несколько слайдов;
- выбрать 1–4 Full HD TV в горизонтальном ряду;
- добавлять базовые элементы;
- перемещать и изменять их размеры;
- настраивать часть визуальных свойств, эффектов и анимации;
- включать Preview;
- сохранять и снова открывать сцену.

На стадии UX-прототипа данные сцен временно находятся в `localStorage`. Это не целевое хранилище продукта.

## Установка

Рабочие серверы следует устанавливать из стабильной ветки `main`, а не из `prototype`.

```bash
bash <(curl -Ls https://raw.githubusercontent.com/ghost-raider-afk/MIRA-TV/main/mira-tv.sh)
```

Подробности: [docs/INSTALLATION.md](docs/INSTALLATION.md).
