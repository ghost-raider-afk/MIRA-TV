# Анимация, эффекты и переходы

Новая архитектура не использует отдельный Motion Studio как самостоятельный источник визуального состояния. Анимация является свойством Scene Element или Slide.

## Анимация элемента

У каждого поддерживающего анимацию элемента есть три этапа:

```text
Entrance
Loop
Exit
```

Примеры Entrance:

- none;
- fade;
- slide;
- scale;
- reveal.

Примеры Loop:

- none;
- pulse;
- float;
- subtle drift;
- glow.

Примеры Exit:

- none;
- fade;
- slide;
- scale.

Общие параметры: длительность, задержка, easing и параметры конкретного эффекта.

## Переход слайда

Slide имеет собственную длительность и transition, например fade, slide, wipe или crossfade.

Переключение слайдов является частью общей timeline сцены и должно синхронно работать на всех TV горизонтальной группы.

## Эффекты

Тень, свечение, opacity, blur, mask и другие визуальные свойства не должны создавать отдельные параллельные runtime-модели. Они применяются в Scene Renderer к конкретному элементу или фону.

## Приоритет читаемости

Движение не является целью само по себе. Для меню и информационных экранов анимация не должна снижать читаемость цен, названий и важной информации.

## Производительность

- скрытая анимация приостанавливается;
- невидимый слайд не продолжает тяжёлые эффекты;
- предпочтение отдаётся transform/opacity и другим дешёвым операциям;
- нельзя запускать глобальный `requestAnimationFrame`, если сцена статична;
- изменение параметра одного объекта не должно перезапускать остальные независимые анимации.

## Широкий ряд TV

Анимация объекта, пересекающего несколько TV, вычисляется в глобальных координатах Scene. Каждый Player отображает свою часть объекта по общей временной шкале.

## Preview

Preview запускает ту же timeline-модель, что и Player. Отдельные «похожие» эффекты только для редактора запрещены.
