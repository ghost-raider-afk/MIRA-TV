# Название и брендинг MIRA-TV

Официальное имя продукта — **MIRA-TV**. Оно используется на страницах проекта, в интерфейсе, руководствах, установщике и пользовательских сообщениях.

Для технических идентификаторов используются `mira-tv` (пакет, Docker Compose, команда) и `mira_tv` там, где нужен знак подчёркивания (например, PostgreSQL database name). Не вводите параллельные написания или старые названия.

Оригинальные SVG-ресурсы бренда находятся в `src/web/admin-ui/public/brand/`. Через админку можно менять оформление конкретного экземпляра, логотипы и цвета в предусмотренных настройках; пользовательский бренд не меняет каноническое имя продукта.

Системные темы меню имеют собственные стили, типографику и декор. Отображение логотипов и названий в темах должно сохранять единый renderer и Preview/TV parity.

Текущую версию проекта определяйте по `package.json` и [GitHub Releases](https://github.com/ghost-raider-afk/MIRA-TV/releases), а не по фиксированному номеру в этом документе.
