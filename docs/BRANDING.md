# Название и оформление MIRA-TV

Официальное название проекта — **MIRA-TV**.

Эта форма используется в интерфейсе, документации, сообщениях установщика и на публичных страницах проекта.

## Технические имена

В местах, где пробелы или заглавные буквы неудобны, используется:

```text
mira-tv
```

Например:

- имя Docker Compose проекта;
- имя npm-пакета;
- имена контейнеров;
- служебные каталоги и внутренние идентификаторы.

Если дефис использовать нельзя, допустима форма:

```text
mira_tv
```

Например, для имени базы данных.

## Единое название

В новых файлах, экранах, настройках и документации не должны появляться прежние названия проекта.

Это важно не только для внешнего вида. Единые имена уменьшают вероятность ошибок при установке, обновлении и работе с Docker.

## Логотип и значок сайта

Файлы логотипа и значка сайта хранятся внутри проекта.

Логотип должен оставаться читаемым:

- в панели администратора;
- на странице входа;
- на тёмном фоне плеера;
- при небольшом размере.

## Пользовательское оформление

Администратор может менять оформление своего экземпляра MIRA-TV через настройки приложения. Пользовательские логотипы и цвета не меняют официальное название самого проекта.

## Версия

Новая самостоятельная линия MIRA-TV начинается с версии **1.0.0**.
