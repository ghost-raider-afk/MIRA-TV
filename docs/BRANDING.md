# Название и продуктовый характер MIRA-TV

Официальное публичное название — **MIRA-TV**.

Техническая форма — `mira-tv`, а там, где дефис невозможен, — `mira_tv`.

## Продуктовый характер

MIRA-TV должна восприниматься как профессиональный инструмент, который не требует профессионального дизайнера для базовой работы.

Внешний вид интерфейса подчинён содержимому:

- Canvas важнее декоративного chrome;
- акцентный цвет используется дозированно;
- визуальная иерархия важнее количества карточек;
- интерфейс не должен выглядеть перегруженной админкой;
- микроанимации интерфейса допустимы только если помогают понять действие;
- светлая и тёмная темы не должны мигать при навигации.

Подробный контракт: [UX-PRINCIPLES.md](UX-PRINCIPLES.md).

## Пользовательский бренд

Логотип, цвета и оформление конкретной установки могут настраиваться администратором, но это не меняет официальное имя продукта и внутренние стабильные идентификаторы без причины.

## Старые названия

В новых экранах, документах и сообщениях нельзя возвращать прежнее публичное название продукта. Legacy internal ID допускаются только там, где их изменение ломает upgrade path или совместимость.
