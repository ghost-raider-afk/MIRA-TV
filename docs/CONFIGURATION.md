# Настройка MIRA-TV

Основные серверные настройки MIRA-TV находятся в одном файле:

```text
/opt/MIRA-TV/.env
```

Установщик создаёт этот файл автоматически. В большинстве случаев после установки достаточно изменить только те параметры, которые действительно нужны вашему серверу.

## Важно

Файл `.env` содержит пароли и служебные секреты.

Не публикуйте его в GitHub, не отправляйте целиком в чаты и не храните в общедоступном месте.

После изменения настроек обычно достаточно выполнить:

```bash
cd /opt/MIRA-TV
sudo docker compose up -d
```

Если менялись параметры, влияющие на сборку приложения, используйте:

```bash
sudo docker compose up -d --build --wait
```

## Домен и HTTPS

```text
MIRA_TV_DOMAIN=
MIRA_TV_ACME_EMAIL=
```

`MIRA_TV_DOMAIN` — доменное имя приложения без `https://`.

Пример:

```text
MIRA_TV_DOMAIN=menu.example.com
```

`MIRA_TV_ACME_EMAIL` — email для автоматического получения HTTPS-сертификата.

## База данных

Основные параметры PostgreSQL:

```text
POSTGRES_DB=mira_tv
POSTGRES_USER=mira_tv
POSTGRES_PASSWORD=...
```

Пароль создаётся установщиком автоматически.

Не меняйте параметры подключения к базе без необходимости на уже работающей установке.

Параметр:

```text
POSTGRES_POOL_MAX=5
```

ограничивает количество одновременных соединений приложения с базой данных. Значение по умолчанию подходит для обычной небольшой установки.

## Учётная запись администратора

При первой установке используются:

```text
BOOTSTRAP_ADMIN_USERNAME=
BOOTSTRAP_ADMIN_PASSWORD=
```

Эти значения нужны для создания первого администратора.

Правила паролей задаются параметрами:

```text
PASSWORD_MIN_LENGTH=10
PASSWORD_MAX_LENGTH=32
GENERATED_PASSWORD_LENGTH=10
```

## Время жизни входа в систему

```text
SESSION_TTL_HOURS=12
```

Определяет, сколько часов может действовать вход администратора без повторной авторизации.

```text
SECURE_COOKIES=true
```

Для публичной установки с HTTPS это значение должно оставаться `true`.

## Защита страницы входа

```text
LOGIN_MAX_ATTEMPTS=8
LOGIN_IP_MAX_ATTEMPTS=32
LOGIN_WINDOW_MINUTES=15
```

Эти параметры ограничивают слишком частые неудачные попытки входа.

Стандартные значения рекомендуется менять только при понятной причине.

## Подключение телевизора

```text
DEVICE_ACTIVATION_TTL_MINUTES=2
DEVICE_ACTIVATION_POLL_SECONDS=2
```

Первый параметр задаёт срок действия временного кода подключения телевизора.

Второй определяет, как часто ещё не подключённый телевизор проверяет, подтверждена ли его привязка. Этот частый запрос используется только во время подключения, а не во время обычного показа меню.

```text
DEVICE_SESSION_TTL_DAYS=365
```

Определяет срок действия авторизации уже подключённого телевизора.

## Проверка изменений на телевизоре

```text
PLAYER_FALLBACK_POLL_SECONDS=60
```

Обычно телевизор получает уведомление об изменении сразу. Если постоянное соединение временно недоступно, этот параметр задаёт интервал резервной проверки сервера.

Слишком маленькое значение увеличит ненужную сетевую нагрузку. Значение `60` секунд является безопасным стандартным вариантом.

## Локальный журнал телевизора

```text
PLAYER_LOG_BATCH_SIZE=100
PLAYER_LOG_LOCAL_MAX_ENTRIES=5000
PLAYER_LOG_LOCAL_MAX_BYTES=10485760
```

Эти параметры ограничивают объём диагностических записей, которые телевизор может временно хранить локально при отсутствии связи.

Увеличивать значения без необходимости не рекомендуется.

## Журнал событий сервера

```text
EVENT_JOURNAL_RETENTION_DAYS=30
EVENT_JOURNAL_MAX_ENTRIES=5000
```

Определяют срок и максимальное количество записей журнала событий.

## Размеры запросов и меню

```text
JSON_BODY_MAX_BYTES=65536
MENU_DRAFT_MAX_BYTES=49152
```

Это защитные ограничения на размер данных, отправляемых в приложение.

Обычному пользователю менять их не требуется.

## Максимальный размер экрана

```text
SCREEN_MAX_WIDTH=1920
SCREEN_MAX_HEIGHT=1080
```

По умолчанию MIRA-TV ограничивает рабочую область разрешением Full HD `1920×1080`.

## Загружаемые изображения и видео

Основные ограничения:

```text
SITE_LOGO_MAX_BYTES=2097152
SITE_FAVICON_MAX_BYTES=524288
SCREEN_BACKGROUND_MAX_BYTES=20971520
ENTITY_ASSET_MAX_BYTES=104857600
```

Они задают максимальный размер:

- логотипа;
- значка сайта;
- фона экрана;
- отдельного изображения или видео сцены.

Перед увеличением лимита убедитесь, что сервер и телевизоры действительно способны удобно работать с более тяжёлыми файлами.

## Ограничение памяти контейнеров

```text
APP_MEMORY_LIMIT=768m
DB_MEMORY_LIMIT=1g
PROXY_MEMORY_LIMIT=256m
```

Эти значения ограничивают использование оперативной памяти отдельными контейнерами.

Для небольшого сервера значения по умолчанию являются отправной точкой. Если на сервере много экранов или крупный каталог, объём памяти можно увеличить.

## Ограничение количества процессов

```text
APP_PIDS_LIMIT=256
DB_PIDS_LIMIT=256
PROXY_PIDS_LIMIT=128
```

Это защитные ограничения Docker. Обычно менять их не требуется.

## Демонстрационные данные

```text
SEED_DEMO_DATA=false
```

При `false` установка не добавляет демонстрационные данные.

Для рабочей установки рекомендуется оставлять `false`.

## Где посмотреть полный список

Актуальный пример всех параметров находится в файле:

```text
.env.example
```

При обновлении установщик добавляет отсутствующие новые параметры в рабочий `.env`, не заменяя существующие секреты.
