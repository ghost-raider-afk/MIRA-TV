# Проверка новой установки

Этот список помогает проверить MIRA-TV после первой установки или после переноса на новый сервер.

## 1. Проверка Docker

Перейдите в каталог приложения:

```bash
cd /opt/MIRA-TV
```

Проверьте конфигурацию:

```bash
sudo docker compose config --quiet
```

Запустите приложение:

```bash
sudo docker compose up -d
```

Проверьте контейнеры:

```bash
sudo docker compose ps
```

Все основные контейнеры должны быть запущены без постоянных перезапусков.

## 2. Проверка сайта

Откройте:

```text
https://ваш-домен
```

Проверьте:

- страница открывается;
- браузер не показывает ошибку сертификата;
- форма входа работает;
- администратор может войти в систему.

## 3. Проверка базы данных

PostgreSQL должен быть доступен приложению внутри Docker, но не должен требовать отдельного публичного порта в интернете.

Проверьте состояние:

```bash
sudo docker compose ps db
```

## 4. Проверка сохранения данных

Создайте тестовую торговую точку или измените безопасную настройку.

Перезапустите контейнеры:

```bash
sudo docker compose restart
```

После перезапуска данные должны сохраниться.

## 5. Проверка телевизора

Откройте:

```text
https://ваш-домен/player
```

Проверьте:

- появляется экран подключения;
- отображается QR-код или короткий код;
- телевизор можно привязать к экрану;
- после привязки появляется меню.

## 6. Проверка обновления меню

Измените меню в панели администратора и сохраните его.

Проверьте, что подключённый телевизор получает изменение без ручной перезагрузки страницы.

## 7. Проверка работы без сети

После того как экран успешно загрузился на телевизоре, временно отключите доступ телевизора к серверу.

Проверьте, что последнее рабочее меню продолжает отображаться.

После восстановления связи изменения должны снова приходить автоматически.

## 8. Проверка медиа

Если используются изображения или видео:

- убедитесь, что они загружаются;
- перезапустите страницу плеера;
- проверьте, что уже загруженные файлы не скачиваются без необходимости;
- проверьте плавность видео на целевом телевизоре.

## 9. Проверка обычных команд Docker Compose

Управление системой должно работать непосредственно из `/opt/MIRA-TV`:

```bash
sudo docker compose stop
sudo docker compose start
sudo docker compose restart
sudo docker compose logs -f
```

Не должны требоваться дополнительные `-p`, `-f` или отдельный файл окружения.

## 10. Проверка обновления

Проверьте команду состояния:

```bash
sudo mira-tv status
```

Проверьте наличие обновлений:

```bash
sudo mira-tv check-update
```

На рабочем сервере не выполняйте обновление только ради теста, если новая версия действительно не требуется.

## 11. Проверка удаления

Убедитесь, что понимаете разницу:

- `mira-tv remove` — удаляет приложение, но сохраняет данные Docker volumes;
- `mira-tv purge` — полностью удаляет приложение и данные после подтверждения.

Команду `purge` на рабочем сервере для проверки не запускайте.

## 12. Проверка безопасности

Перед вводом системы в эксплуатацию убедитесь, что:

- `.env` не доступен через веб;
- файл `.env` не опубликован в GitHub;
- используются HTTPS и безопасные cookie;
- база данных не опубликована напрямую в интернет;
- наружу открыты только необходимые порты;
- пароль администратора сохранён в безопасном месте.

## 13. Проверка нагрузки телевизора

При статическом меню и отсутствии изменений телевизор не должен постоянно перерисовывать экран или выполнять частые сетевые запросы.

Если на экране есть видео или анимация, работу должны выполнять только действительно видимые элементы.
