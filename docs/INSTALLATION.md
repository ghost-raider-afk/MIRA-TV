# Установка MIRA-TV

Эта инструкция описывает установку и обновление MIRA-TV на сервере с Ubuntu.

## Что понадобится

Перед началом подготовьте:

- VPS или отдельный сервер с Ubuntu;
- доменное имя для MIRA-TV;
- DNS-запись домена, направленную на IP-адрес сервера;
- открытые сетевые порты `80` и `443`;
- доступ к серверу с правами `root` или через `sudo`;
- доступ сервера в интернет для загрузки исходного кода и Docker-образов.

Дополнительный порт для передачи файлов на телевизоры не нужен.

## Быстрая установка

Вставьте одну команду:

```bash
bash <(curl -Ls https://raw.githubusercontent.com/ghost-raider-afk/MIRA-TV/main/mira-tv.sh)
```

Сразу откроется меню установщика:

```text
1) Установить
2) Проверить обновление
3) Статус
4) Перезапустить
5) Логи
6) Сбросить пароль администратора
7) Удалить приложение
8) Удалить приложение и данные
0) Выход
```

Для первой установки выберите `1`.

Если команда запущена не от `root`, меню всё равно откроется. После выбора операции, которой нужны административные права, установщик сам запустит её через `sudo`.

Во время установки потребуется указать:

1. доменное имя без `https://`;
2. email для получения HTTPS-сертификата;
3. имя администратора.

Пароль администратора, пароль базы данных и служебный секрет создаются автоматически.

После успешной установки пароль администратора показывается один раз. Сохраните его в надёжном месте.

## Что создаётся на сервере

Основной каталог приложения:

```text
/opt/MIRA-TV
```

Файл настроек:

```text
/opt/MIRA-TV/.env
```

Команда управления:

```text
/usr/local/bin/mira-tv
```

Все серверные компоненты запускаются вместе с помощью Docker Compose.

## Проверка после установки

Перейдите в каталог приложения:

```bash
cd /opt/MIRA-TV
```

Проверьте состояние контейнеров:

```bash
sudo docker compose ps
```

Проверьте последние сообщения приложения:

```bash
sudo docker compose logs --tail=200
```

Для просмотра новых сообщений в реальном времени:

```bash
sudo docker compose logs -f
```

Также откройте в браузере:

```text
https://ваш-домен
```

Если страница открывается по HTTPS и контейнеры работают без постоянных перезапусков, базовая установка завершена.

## Меню установщика

После установки то же меню открывается короткой командой:

```bash
mira-tv
```

Для операций, которым нужны права администратора, установщик сам использует `sudo`.

В меню доступны:

1. Установить
2. Проверить обновление
3. Статус
4. Перезапустить
5. Логи
6. Сбросить пароль администратора
7. Удалить приложение
8. Удалить приложение и данные
0. Выход

Пункт **«Логи»** показывает последние сообщения контейнеров и продолжает выводить новые сообщения в реальном времени.

## Обновление

В меню используется один пункт **«Проверить обновление»**.

Если установлена последняя версия, MIRA-TV сообщает об этом и ничего не изменяет.

Если доступен новый релиз, установщик показывает текущую и новую версии и спрашивает:

```text
Обновить? [y/N]
```

При ответе `y` начинается обновление. Любой другой ответ отменяет его.

То же действие можно запустить напрямую:

```bash
mira-tv update
```

Перед изменением приложения установщик создаёт временную резервную копию:

- текущих файлов приложения;
- файла `.env`;
- текущего установщика;
- текущей версии исходного кода;
- базы PostgreSQL.

Загруженные изображения и видео находятся в отдельном постоянном хранилище и обычным обновлением не удаляются.

После переключения на новую версию установщик проверяет конфигурацию и запускает контейнеры. Если обновление не проходит проверку, автоматически восстанавливаются предыдущая версия приложения, настройки и база данных.

После успешного обновления временная резервная копия удаляется автоматически.

## Сброс пароля администратора

Через меню выберите **«Сбросить пароль администратора»** или выполните:

```bash
mira-tv reset-admin-password
```

Новый пароль создаётся автоматически. Старые веб-сессии этого администратора завершаются.

## Управление через Docker Compose

MIRA-TV не требует специальных команд для обычной работы с Docker.

Запуск:

```bash
cd /opt/MIRA-TV
sudo docker compose up -d
```

Просмотр состояния:

```bash
sudo docker compose ps
```

Логи:

```bash
sudo docker compose logs -f
```

Перезапуск:

```bash
sudo docker compose restart
```

Остановка контейнеров без удаления:

```bash
sudo docker compose stop
```

Повторный запуск:

```bash
sudo docker compose start
```

Остановка и удаление контейнеров с сохранением данных:

```bash
sudo docker compose down
```

Пересборка после изменения исходного кода:

```bash
sudo docker compose up -d --build --wait
```

Проверка файла `compose.yaml`:

```bash
sudo docker compose config --quiet
```

## Важно о данных

Команда:

```bash
sudo docker compose down
```

не удаляет базу данных и загруженные файлы.

Команда:

```bash
sudo docker compose down -v
```

удаляет постоянные хранилища Docker вместе с данными MIRA-TV. Используйте её только если действительно хотите полностью удалить данные проекта.

## Удаление

Удалить приложение, сохранив постоянные данные Docker:

```bash
mira-tv remove
```

Полностью удалить приложение вместе с базой, загруженными файлами и сертификатами:

```bash
mira-tv purge
```

Обе операции требуют явного подтверждения `YES`. Простое нажатие Enter или ответ `NO` отменяет удаление.
