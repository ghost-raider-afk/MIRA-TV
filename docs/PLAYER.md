# MIRA-TV Player

MIRA-TV Player — это страница, которая открывается на телевизоре и показывает назначенный ему экран.

Адрес плеера:

```text
https://ваш-домен/player
```

## Подключение телевизора

При первом открытии плеер показывает QR-код и короткий цифровой код.

Чтобы подключить телевизор:

1. откройте раздел подключения телевизоров в панели администратора;
2. выберите торговую точку и нужный экран;
3. отсканируйте QR-код или введите короткий код;
4. подтвердите подключение.

После этого телевизор получает настройки выбранного экрана.

## Что хранится на телевизоре

Плеер сохраняет только те данные, которые нужны для стабильного показа:

- последнюю успешно показанную версию экрана;
- уже загруженные изображения и видео;
- служебную информацию для проверки обновлений;
- небольшой журнал ошибок и важных событий.

Полная база данных приложения на телевизор не копируется.

## Работа без связи

После успешной загрузки меню телевизор может продолжать его показывать даже при временной потере связи с сервером.

При запуске плеер сначала пытается открыть последнюю рабочую версию, сохранённую локально. Поэтому уже настроенный телевизор не должен показывать пустой экран только из-за кратковременной проблемы с сетью.

Когда соединение возвращается, плеер проверяет, изменилось ли содержимое.

## Как плеер узнаёт об изменениях

При нормальной работе сервер отправляет телевизору короткое уведомление о том, что экран изменился.

После этого телевизор запрашивает актуальные данные по HTTPS.

Само меню, изображения и видео не передаются внутри уведомления.

Если постоянное соединение недоступно, включается резервная проверка сервера с более редким интервалом.

## Почему плеер не скачивает всё заново

Экран разделён на отдельные части: меню, фон, медиа, текстовые блоки и другие элементы.

Сервер и телевизор сравнивают состояние этих частей. Если изменилась только одна из них, остальные не требуется получать и создавать заново.

Это уменьшает сетевой трафик и нагрузку на телевизор.

## Безопасное обновление экрана

Новая версия экрана считается рабочей только после того, как плеер смог подготовить необходимые данные и показать её.

Например, если для нового меню нужен фон, который не удалось загрузить, предыдущая рабочая версия не удаляется.

Это защищает телевизор от ситуации, когда неудачное обновление заменяет исправный экран пустой или неполной версией.

## Изображения и видео

Уже загруженные файлы сохраняются в стандартном кэше браузера.

Плеер повторно использует их, пока они нужны текущему экрану.

Когда рабочая версия экрана успешно заменена новой, больше не используемые файлы могут быть удалены из локального кэша.

Очистка выполняется только после успешного обновления, чтобы не удалить файлы действующего экрана заранее.

## Видео

Видео воспроизводится стандартным механизмом браузера.

MIRA-TV не разбирает каждый кадр видео в JavaScript. Это позволяет использовать аппаратное ускорение телевизора там, где оно поддерживается.

Если видео скрыто и не участвует в текущей сцене, плеер приостанавливает его.

## Анимация

Плеер также приостанавливает невидимые анимации. Например, базовые эффекты не должны продолжать работать под полноэкранной временной сценой.

При сворачивании или скрытии страницы ненужная фоновая работа также уменьшается.

## Журнал плеера

Если во время работы возникает важное событие или ошибка, плеер может временно сохранить запись локально.

Когда связь восстановится, записи отправляются на сервер небольшими группами.

Журнал имеет ограниченный размер и не должен бесконечно занимать память телевизора.

## Что происходит, когда ничего не меняется

В нормальном состоянии:

- статическое меню не создаётся заново;
- файлы не загружаются повторно;
- база данных браузера не записывается без причины;
- сервер не отправляет постоянный поток данных;
- работает только то видео или анимация, которые действительно видны на экране.
