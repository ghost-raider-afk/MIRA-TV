# Документация MIRA-TV

Добро пожаловать в документацию MIRA-TV.

Если вы впервые открыли проект, начните с установки и краткого руководства по работе.

## Для установки

[INSTALLATION.md](INSTALLATION.md) — установка на Ubuntu, запуск Docker Compose, обновление и удаление.

[CONFIGURATION.md](CONFIGURATION.md) — основные настройки файла `.env` простым языком.

[DEPLOYMENT-CHECKLIST.md](DEPLOYMENT-CHECKLIST.md) — список проверок после новой установки или переноса на другой сервер.

## Для повседневной работы

[USAGE.md](USAGE.md) — создание торговой точки, каталога, экрана и подключение телевизора.

[PLAYER.md](PLAYER.md) — как работает страница плеера на телевизоре, работа без сети и локальное хранение файлов.

[ANIMATION.md](ANIMATION.md) — изображения, видео, текстовые элементы, анимация и временные сцены.

## Для администрирования

[TROUBLESHOOTING.md](TROUBLESHOOTING.md) — базовая диагностика сайта, Docker, базы данных и телевизоров.

[PERFORMANCE.md](PERFORMANCE.md) — принципы экономии ресурсов телевизора и практические рекомендации.

## Для понимания проекта

[ARCHITECTURE.md](ARCHITECTURE.md) — общая схема MIRA-TV без привязки к внутренним классам и файлам исходного кода.

[BRANDING.md](BRANDING.md) — официальное название MIRA-TV и правила технических имён.

[ROADMAP.md](ROADMAP.md) — общие направления дальнейшего развития.

## История версий

История заметных изменений находится в корневом файле [CHANGELOG.md](../CHANGELOG.md).

## Принцип документации

Документация описывает то, что полезно человеку, который устанавливает, использует, администрирует или изучает MIRA-TV.

Внутренние названия функций, классов и временные решения разработки не должны быть обязательны для понимания системы.
