# Конструктор сцен MIRA-TV

Этот документ описывает целевую пользовательскую модель конструктора сцен. Ветка `prototype` уже содержит первый интерактивный каркас, но часть описанных возможностей ещё не подключена к серверу и TV Player.

## Сцена

Сцена — самостоятельный визуальный проект, не привязанный к торговой точке и конкретному телевизору.

Сцена содержит один или несколько слайдов. Каждый слайд имеет фон, длительность, переход и собственный набор элементов.

```text
Scene
 ├─ Slide 1
 │   ├─ Background
 │   ├─ Table
 │   ├─ Text
 │   ├─ Logo
 │   ├─ Video
 │   ├─ Weather
 │   └─ Clock
 ├─ Slide 2
 └─ Slide N
```

## Сохранение как шаблон

Пользователь собирает сцену в конструкторе и сохраняет её как повторно используемый шаблон. Шаблон не должен содержать привязку к конкретной торговой точке или физическому TV.

Один шаблон можно назначить нескольким торговым точкам и группам телевизоров.

## Структура интерфейса

Конструктор состоит из четырёх зон:

- верхняя командная панель — имя сцены, Preview, сохранение и общие действия;
- левая панель — добавление элементов и настройка фона;
- центральный Canvas — сама сцена;
- правая панель — свойства выбранного элемента или слайда;
- нижняя лента — слайды и их порядок.

Canvas всегда является главным рабочим пространством. Панели не должны перекрывать его.

## Фон слайда

Фон является свойством слайда. Целевая модель поддерживает:

- цвет;
- градиент;
- изображение;
- видео.

Дополнительные параметры могут включать заполнение, позицию, затемнение, прозрачность и размытие.

## Элементы

Базовый набор целевой архитектуры:

- таблица каталога;
- текст;
- изображение;
- логотип;
- видео;
- погода;
- часы;
- QR-код;
- бегущая строка;
- фигура/подложка.

Новый тип элемента должен подключаться через единый контракт, а не через отдельный редактор и отдельный runtime.

## Общие свойства элемента

Каждый элемент имеет общую геометрию и состояние:

```text
id
type
x
y
width
height
z_index
opacity
visible
locked
style
data_binding
animation
effects
```

Координаты задаются в логическом пространстве Canvas и не зависят от текущего масштаба редактора.

## Прямое редактирование

На Canvas пользователь должен уметь:

- выбрать элемент;
- переместить;
- изменить размер;
- дублировать;
- удалить;
- изменить слой;
- заблокировать;
- отменить/повторить действие.

Изменение свойств должно отображаться сразу, без отдельной кнопки «Применить» для каждого поля.

## Таблица

Table Element является обычным элементом сцены, но получает данные из каталога.

В его настройках пользователь выбирает источник данных, колонки, сортировку, фильтры, отображаемые объёмы и визуальный стиль.

Таблица не должна быть жёстко привязана к пиву или ресторану.

## Часы

Часы добавляются как готовый информер. На первом уровне пользователь выбирает визуальный вариант, например:

- цифровые;
- цифровые с датой;
- минималистичные;
- аналоговые.

Тонкие настройки раскрываются дополнительно.

## Погода

Погода также является обычным Widget Element. Возможные варианты:

- температура;
- температура + состояние;
- компактная карточка;
- текущая погода + прогноз.

TV Player не должен обращаться к внешнему погодному API напрямую. Данные должен получать и кешировать сервер MIRA-TV.

## Видео и изображения

Медиа выбираются из медиатеки. Сцена хранит ссылку на Asset ID, а не произвольный путь к файлу.

Видео воспроизводится стандартным механизмом браузера. JavaScript не должен вручную декодировать кадры.

## Эффекты

Эффекты принадлежат элементу или слайду. Базовый набор может включать тень, свечение, прозрачность, blur, скругление и маску.

Эффект не должен создавать отдельную глобальную подсистему.

## Анимация

У элемента три независимых этапа:

```text
Entrance
Loop
Exit
```

У слайда отдельно задаются длительность и переход к следующему слайду.

## Несколько телевизоров

MIRA-TV поддерживает объединение TV только в горизонтальный ряд.

```text
TV 1 | TV 2 | TV 3 | TV 4
```

Для Full HD:

```text
1 TV = 1920×1080
2 TV = 3840×1080
3 TV = 5760×1080
4 TV = 7680×1080
```

Это одна общая сцена. Границы физических телевизоров показываются направляющими, но объект может пересекать их.

## Preview

Preview должен скрывать служебные элементы конструктора и запускать реальную сцену тем же Scene Renderer, который используется TV Player.

Запрещено поддерживать два независимых алгоритма отображения сцены.

## Статус прототипа

Сейчас в `prototype` уже можно создать сцену, добавлять несколько слайдов, использовать Canvas на 1–4 TV и работать с базовыми объектами. Хранение временно находится в `localStorage`. Серверное хранилище, медиатека, реальные информеры и назначение сцен на TV будут подключаться после утверждения UX.
