# Screenlite Web Kiosk для Android TV

MIRA-TV может показывать на экране подключения ТВ ссылку на установочный APK **Screenlite Web Kiosk**.

- Источник: https://github.com/screenlite/android-web-kiosk
- Лицензия: MIT (автор Screenlite; приложение не является частью MIRA-TV).
- Зафиксированная версия: **v0.0.11**.
- Официальный файл: `screenlite-web-kiosk-v0-0-11.apk` (10 109 088 байт).
- SHA-256: `462cc87ae09620dfce9d7a7ec1005fa6fffef7f4b72c14b51599e83a423e8559`.

Во время сборки production Docker-образа APK загружается из официального GitHub Release и проверяется по указанной контрольной сумме. Во время эксплуатации телевизор скачивает APK **с сервера MIRA-TV** по адресу `/downloads/screenlite-web-kiosk-v0-0-11.apk`. Работающий сервер не зависит от GitHub и не обновляет APK автоматически. Обновление версии APK требует отдельного изменения Dockerfile и проверки.

Администратор включает ссылку в «Настройки → Основные параметры → Размер и обновление». По умолчанию настройка выключена. Она влияет **только на видимость ссылки при подключении ТВ**, а не на доступность прямого URL и не устанавливает приложение автоматически.

После загрузки APK приложение требуется вручную установить на Android TV, разрешить установку из этого источника при необходимости, открыть настройки Screenlite и ввести URL `https://<домен-MIRA-TV>/player`. Cookies, IndexedDB, Service Worker и LKG старого браузера не переносятся, поэтому потребуется повторно авторизовать ТВ. Перед вводом в эксплуатацию проверьте на одном устройстве fullscreen при перезагрузке страницы, длительную офлайн-работу LKG, перезагрузку телевизора и настройки фоновых повторных загрузок.

**Важно:** Screenlite Web Kiosk имеет собственный WebView и может реагировать на сетевые ошибки иначе, чем стандартный браузер. Не распространяйте его массово без проверки Local-first MIRA-TV на физическом ТВ.
