# Поиск и устранение проблем

Эта страница содержит базовые проверки, которые безопасно выполнять при большинстве проблем с MIRA-TV.

## С чего начать

Перейдите в каталог приложения:

```bash
cd /opt/MIRA-TV
```

Проверьте состояние контейнеров:

```bash
sudo docker compose ps
```

Посмотрите последние сообщения:

```bash
sudo docker compose logs --tail=200
```

Для просмотра новых сообщений в реальном времени:

```bash
sudo docker compose logs -f
```

## Сайт не открывается

Проверьте:

1. что контейнеры запущены;
2. что домен указывает на правильный IP-адрес;
3. что порты `80` и `443` доступны снаружи;
4. что компонент HTTPS работает без ошибок;
5. что в `.env` указан правильный домен.

Полезные команды:

```bash
sudo docker compose ps
sudo docker compose logs proxy --tail=200
sudo docker compose logs app --tail=200
```

## Контейнер постоянно перезапускается

Посмотрите сообщения конкретного контейнера:

```bash
sudo docker compose logs app --tail=200
```

или:

```bash
sudo docker compose logs db --tail=200
```

После исправления причины можно выполнить:

```bash
sudo docker compose up -d
```

Не удаляйте постоянные хранилища Docker в попытке «починить» запуск, пока не понятно, что проблема действительно связана с данными.

## Ошибка подключения к базе данных

Проверьте состояние PostgreSQL:

```bash
sudo docker compose ps db
sudo docker compose logs db --tail=200
```

Проверьте, что в `.env` не были случайно изменены:

- имя базы;
- пользователь;
- пароль;
- имя сервиса базы данных.

На уже установленной системе не меняйте пароль базы только ради проверки — это может привести к рассинхронизации настроек.

## Не получается войти в панель

Проверьте:

- правильность имени пользователя;
- регистр символов в пароле;
- не было ли слишком много неудачных попыток входа;
- системное время сервера;
- сообщения приложения.

```bash
sudo docker compose logs app --tail=200
```

## Телевизор не показывает QR-код

Откройте на телевизоре:

```text
https://ваш-домен/player
```

Проверьте:

- доступен ли сайт по HTTPS;
- правильно ли установлено время на телевизоре;
- не блокирует ли браузер загрузку страницы;
- открывается ли этот же адрес на другом устройстве в той же сети.

## QR-код есть, но телевизор не подключается

Попробуйте:

1. обновить временный код;
2. использовать короткий цифровой код вместо камеры;
3. проверить, что в панели выбраны правильная торговая точка и экран;
4. посмотреть журнал приложения.

Временный код подключения имеет ограниченный срок действия. Если он устарел, нужно получить новый.

## Телевизор подключён, но не получает изменения

Проверьте сначала, было ли изменение сохранено в редакторе.

Затем:

1. убедитесь, что телевизор привязан к нужному экрану;
2. проверьте доступ телевизора к серверу;
3. подождите резервную проверку — она используется, если постоянное соединение временно недоступно;
4. при необходимости откройте логи приложения.

Перезагрузка плеера не должна быть обязательной частью обычной работы.

## Телевизор показывает старое меню после потери связи

Это ожидаемое поведение, если сервер недоступен.

MIRA-TV специально сохраняет последнюю рабочую версию, чтобы экран не становился пустым.

После восстановления связи плеер должен получить изменения автоматически.

Если сервер уже доступен, но экран долго не обновляется, проверьте сетевое соединение телевизора и сообщения сервера.

## Не загружается фон, изображение или видео

Проверьте:

- размер файла;
- формат файла;
- ограничения размера в `.env`;
- свободное место на сервере;
- сообщения приложения.

Для видео рекомендуется MP4 или WebM.

Если новое обязательное изображение не загрузилось, MIRA-TV должна оставить прежнюю рабочую версию экрана вместо замены её неполной.

## Видео воспроизводится плохо

Причина часто находится на стороне конкретного телевизора или его браузера.

Попробуйте:

- уменьшить разрешение видео до разрешения экрана;
- уменьшить размер и качество видеофайла;
- сохранить ролик в другом совместимом формате;
- проверить тот же файл напрямую в браузере телевизора;
- убрать одновременно работающие тяжёлые эффекты.

## Закончилось место на диске

Проверьте свободное место:

```bash
df -h
```

Посмотрите, сколько места занимает Docker:

```bash
sudo docker system df
```

Не запускайте `docker system prune -a` вслепую на сервере с другими проектами. Сначала убедитесь, какие данные будут удалены.

## Проверка Docker Compose

Если после ручного изменения конфигурации приложение не запускается:

```bash
cd /opt/MIRA-TV
sudo docker compose config --quiet
```

Если команда выводит ошибку, исправьте `compose.yaml` или `.env` до запуска контейнеров.

## После обновления появилась проблема

Сначала проверьте:

```bash
sudo mira-tv status
sudo docker compose ps
sudo docker compose logs --tail=200
```

Убедитесь, что `.env` сохранил старые секреты и получил новые обязательные параметры.

## Когда собирать информацию для сообщения об ошибке

Полезно приложить:

- версию MIRA-TV;
- версию Ubuntu;
- вывод `docker compose ps`;
- относящиеся к проблеме строки журнала;
- точные шаги, после которых появилась ошибка;
- модель и браузер телевизора, если проблема связана с плеером.

Не публикуйте содержимое `.env`, пароли, cookie, токены подключения и другие секреты.
