# Целевой рабочий процесс MIRA-TV

Этот документ описывает пользовательский поток новой архитектуры. Часть шагов пока является целевым состоянием и ещё не подключена к серверной части `prototype`.

## 1. Заполнить каталог

Пользователь создаёт категории и позиции, указывает цены, объёмы и необходимые характеристики.

Для пива доступны специализированные свойства, но каталог остаётся универсальным для еды, напитков, тары, услуг и других типов данных.

## 2. Открыть «Сцены»

Сцена создаётся отдельно от торговой точки.

При создании пользователь выбирает количество TV в горизонтальном ряду. Один TV — обычный Full HD Canvas, несколько TV — единый широкий Canvas.

## 3. Собрать слайды

Каждая Scene может содержать несколько Slides. Пользователь выбирает фон, длительность и переход слайда.

## 4. Добавить элементы

Из левой панели добавляются:

- таблица;
- текст;
- изображение;
- логотип;
- видео;
- часы;
- погода;
- фигуры и другие информеры.

Элемент появляется сразу на Canvas с разумным размером и может быть перемещён или изменён напрямую.

## 5. Настроить свойства

Правая панель показывает только настройки выбранного объекта. Частые параметры видны сразу, редкие раскрываются дополнительно.

## 6. Настроить таблицу

Пользователь выбирает категорию каталога, нужные колонки и объёмы цены.

Например для базовой цены `400 ₽ / 1 л` можно вывести `0.5 л`, `1 л` и `1.5 л`. Значения рассчитываются автоматически, но любое нужное значение можно переопределить ручным Price Variant.

## 7. Добавить анимацию

Анимация настраивается у элемента через Entrance/Loop/Exit. У слайда отдельно задаётся переход.

## 8. Preview

Preview показывает реальный Scene Renderer без служебных рамок редактора. Для широкой сцены пользователь может смотреть всю панораму или отдельный TV viewport.

## 9. Сохранить как шаблон

Готовая сцена сохраняется для повторного использования. Она ещё не принадлежит конкретной точке.

## 10. Открыть торговую точку

В отдельном разделе пользователь управляет физическими TV и их группами.

## 11. Применить шаблон

Выбранный шаблон назначается одному TV или горизонтальной группе TV.

## 12. Выбрать режим показа

Целевая модель предлагает постоянный показ, чередование сцен и расписание.

## 13. Подключить физические TV

TV подключается по QR-коду или короткому коду и привязывается к конкретному Slot группы.

## 14. Эксплуатация

Изменение дизайна выполняется в Scene Editor. Состояние устройств, расписание и назначение контента — в торговой точке.

Эти две задачи не должны смешиваться в одном редакторе.
