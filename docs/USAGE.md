# Работа с MIRA-TV

Это краткое руководство для первого знакомства с приложением после установки.

## 1. Войдите в панель управления

Откройте адрес MIRA-TV в браузере:

```text
https://ваш-домен
```

Используйте имя администратора и пароль, полученные при установке.

## 2. Создайте торговую точку

Торговая точка объединяет экраны, которые находятся в одном месте.

Например:

- магазин на Ленина;
- бар на Набережной;
- кафе в торговом центре.

После создания точки к ней можно добавлять отдельные экраны.

## 3. Заполните каталог

Каталог хранит товары и другие позиции, которые можно использовать в меню.

Для каждой позиции указываются необходимые данные, например:

- название;
- производитель;
- цена;
- характеристики;
- цвет или тип;
- дополнительные значения, используемые в меню.

Если товаров много, можно использовать импорт CSV.

Перед применением импорта MIRA-TV показывает предварительный результат и позволяет проверить изменения.

## 4. Создайте экран

Экран — это отдельное меню для конкретного телевизора.

Для каждого экрана можно настроить:

- разрешение;
- фон;
- расположение меню;
- шрифт;
- цвета;
- размеры;
- отображаемые позиции;
- изображения и видео;
- текстовые элементы;
- анимацию.

Изменения сначала видны в редакторе. На телевизор они попадают после сохранения.

## 5. Подключите телевизор

На телевизоре откройте страницу MIRA-TV Player:

```text
https://ваш-домен/player
```

Если телевизор ещё не подключён, на экране появится QR-код и короткий код.

В панели администратора откройте раздел подключения телевизора и:

1. выберите торговую точку;
2. выберите экран;
3. отсканируйте QR-код или введите короткий код;
4. подтвердите подключение.

После этого телевизор получит меню выбранного экрана.

## 6. Проверьте обновление меню

Измените любой элемент меню и сохраните экран.

Подключённый телевизор должен получить изменение автоматически.

Перезагружать страницу плеера вручную при обычной работе не требуется.

## Если пропал интернет

Плеер сохраняет последнюю рабочую версию экрана.

При временной потере связи телевизор продолжает показывать уже загруженное меню.

После восстановления соединения MIRA-TV проверяет наличие новой версии и обновляет экран при необходимости.

## Работа с фоном

Для экрана можно загрузить собственное изображение фона.

После загрузки MIRA-TV создаёт для файла отдельный адрес. Это позволяет телевизору безопасно хранить фон локально и не путать старую версию с новой.

## Работа с видео

Видео можно использовать как отдельный элемент сцены.

Чтобы снизить нагрузку на телевизор:

- используйте распространённые форматы MP4 или WebM;
- не загружайте видео с разрешением значительно выше разрешения телевизора без необходимости;
- избегайте слишком большого количества одновременно воспроизводимых видео;
- проверяйте плавность воспроизведения на целевом телевизоре.

MIRA-TV использует стандартное воспроизведение видео браузером.

## Анимация

Анимация настраивается отдельно от содержимого меню.

Основное правило: анимация не должна ухудшать читаемость меню и не должна заставлять телевизор постоянно выполнять тяжёлые вычисления.

Подробнее: [ANIMATION.md](ANIMATION.md).

## Несколько экранов

В одной торговой точке можно создать несколько экранов.

Каждый экран имеет собственные настройки и собственное подключение к телевизору.

Изменение одного экрана не должно обновлять остальные без необходимости.

## Журнал событий

В журнале событий можно проверить действия пользователей и важные события приложения.

При поиске проблемы сначала полезно проверить:

1. журнал событий в панели;
2. состояние Docker-контейнеров;
3. серверные логи.

Подробнее: [TROUBLESHOOTING.md](TROUBLESHOOTING.md).

## Рекомендуемый порядок работы

Для повседневной работы удобно придерживаться такой последовательности:

1. поддерживать каталог товаров в актуальном состоянии;
2. редактировать нужный экран;
3. проверять результат в предпросмотре;
4. сохранять изменения;
5. убедиться, что нужный телевизор получил обновление.
