# MIRA-TV 1.10.0

## Единый Player Scene Runtime

- Preview и реальный TV Player переведены на общий Scene Motion Runtime и единый порядок canonical scene layers.
- Устранены параллельные пути рендера, из-за которых Preview мог отличаться от реального экрана.
- Погода включена в основной Player Context и delta pipeline вместо отдельного независимого bootstrap-renderer.
- Применение сцены выполняется атомарно одной серверной транзакцией и одной render revision для menu motion, promotion, weather, announcement, brand, environment, Entity и Scene Playlist.

## Управление объектами

- Удалён пользовательский глобальный переключатель Motion Engine.
- Для объектов сцены используются две независимые настройки: «Показывать» и «Анимация».
- Отдельные состояния добавлены для меню, акции, погоды, объявления, бренда, аквариума, Entity и Scene Playlist.
- Entity сохраняет отдельное состояние анимации и режим движения.
- Scene Playlist может оставаться активным при отключённых переходах.

## Playlist Studio

- Менеджер объектов перестроен в читаемую двухколоночную структуру для рабочего окна 1600×900.
- Удалена лишняя полоса вкладок; настройки открываются контекстно кнопкой «Настроить».
- Устранено перекрытие элементов управления между соседними карточками.
- Размеры рабочих подписей увеличены; отказались от микроскопических 7–10 px элементов управления.
- Состояние выбранного ТВ отображается отдельно от черновика.

## Погода и Preview

- Weather layer стал штатным слоем SceneLayerComposer.
- Preview использует те же canonical layer-классы и атрибуты, что и TV Player.
- Last Known Good для погоды восстанавливается через общий Player state sync.
- Offline weather cache остаётся изолированным по screen ID.

## Motion и стабильность

- Устранён белый засвет motion effects: белые full-scene glow surfaces убраны из рабочего пути.
- Motion Runtime запускается только для реально активных анимаций.
- Исправлен offline cold start: Service Worker больше не требует отсутствующий `/wasm/mira-motion-kernel.wasm`.
- Для текущей сборки используется детерминированный JavaScript motion kernel fallback, поэтому shell полностью самодостаточен.
- Исправлена гонка открытия секций настроек редактора монитора.

## Проверка релиза

Релиз публикуется только после успешного полного workflow `check`: Node/unit, production Compose и browser-visual Playwright.
