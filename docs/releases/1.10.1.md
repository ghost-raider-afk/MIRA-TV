# MIRA-TV 1.10.1

## Срочное исправление управления ТВ

- выбранный в Preview монитор стал основным адресатом управления;
- переключатели «Показывать» и «Анимация» автоматически применяются к текущему Preview TV через атомарный `/animation/apply`;
- после применения интерфейс повторно читает `screen_animation_settings` конкретного монитора и не полагается только на локальный payload;
- ручная кнопка «Применить на ТВ» всегда видима и отменяет ожидающий live-debounce, поэтому не создаются двойные apply/revision;
- live-apply работает с immutable snapshot и не может перезаписать более новые изменения Preview старым ответом;
- при смене Preview экран автоматически становится текущей целью управления.

## Playlist Studio

- восемь больших кнопок «Настроить» заменены одним выпадающим списком выбора объекта;
- матрица объектов уплотнена до читаемых строк в двух колонках;
- описания убраны из постоянной матрицы, параметры отображаются только для выбранного объекта;
- массовое применение к другим мониторам перенесено в компактный раскрываемый блок;
- основная кнопка применения закреплена в рабочей области;
- активная панель настроек прокручивается внутри себя, а не растягивает всю страницу;
- рабочее окно 1600×900 проверяется browser-тестом без page-level overflow.

## Надёжность

- добавлен browser regression-тест полного пути: UI checkbox → `PUT /api/settings/animation/apply` → конкретный `screen_id` → `screen_animation_settings`;
- устранена гонка между автоматическим и ручным применением;
- устранена гонка, при которой завершившийся старый live-apply мог затереть более новые правки или статус;
- Node, production Compose и browser-visual обязательны перед публикацией.
