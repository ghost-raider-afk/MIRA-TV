# MIRA-TV 1.11.0

## Единая модель сцены

MIRA-TV 1.11.0 переводит визуальный контент на один канонический источник — `scene.elements[]`. Специализированные владельцы Brand, Entity, Announcement, Environment, отдельный Weather и Aquarium больше не участвуют в активном runtime.

Доступны пять типов элементов: «Текстовое поле», «Погода», «Картинка», «Видео» и «Логотип». Legacy Brand/Announcement/Entity/Weather при обновлении сохраняются через миграцию в соответствующие generic elements; Aquarium не переносится.

## Редактор и Preview

- элементы добавляются как «Элемент 1», «Элемент 2» и далее;
- текстовое поле поддерживает расширенное типографическое форматирование и эффекты;
- геометрия задаётся в системе 1920×1080;
- медиа загружаются через независимый scene media API;
- строки меню и названия разделов редактируются прямо в Preview;
- продукция остаётся связанной с общей базой;
- сортировка А→Я выполняется внутри выбранного раздела.

## Общий renderer и TV Player

Preview, TV Player и Manager используют общий `PlayerSceneRenderer` и keyed `SceneElementRenderer`. Узлы сохраняются по `element.id`, video/media не пересоздаются без реальной необходимости.

Player State обновлён до schema v4. Scene-only изменения не перестраивают меню, menu hash использует канонические настройки отображения и не зависит от editor revision. Weather API поставляет данные, но не владеет конфигурацией элемента.

## Playlist Studio

Playlist Studio теперь отвечает только за menu/promo motion и Scene Playlist. Старый object manager и Entity-зависимый Object Story удалены. Временные сцены работают через canonical Player layers и корректно очищают fullscreen/timer ownership.

## Миграции

После переноса legacy visual data migration 023 удаляет старые visual columns и отдельные weather tables. Новые установки и новые мониторы больше не создают retired ownership.

## Проверки

Перед выпуском функциональный HEAD прошёл полный обязательный CI: Node, production Compose и browser-visual. Отдельными E2E проверены generic scene elements, media upload, realtime delta, сохранение keyed DOM, Weather parity и Playlist lifecycle.
