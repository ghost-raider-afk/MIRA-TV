# MIRA-TV 1.13.11

Точечное улучшение страницы «Мониторы» после внедрения TV-сети.

- Убран пульсирующий/движущийся эффект на телевизорах без связи — offline и неподключённые экраны теперь статичные.
- Фактический кадр TV Player для карточек и увеличенного просмотра повышен до 720 px по ширине с более высоким качеством WebP.
- Сохранён единый лимит `TV_PREVIEW_MAX_BYTES`: сложные кадры автоматически деградируют по quality/размеру и не ломают публикацию.
- Player offline shell обновлён до v28 для гарантированного получения нового capture-модуля.
- Ping по-прежнему измеряется только при открытии/перезагрузке страницы «Мониторы» и ручном «Обновить», но теперь переживает короткую гонку переподключения Player.
- UI показывает реальный RTT в мс; отсутствие измерения и отсутствие ответа различаются явно.
- Добавлены регрессии на статичный offline-экран, bounded 720px preview и видимый ping в миллисекундах.
