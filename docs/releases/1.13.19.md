# MIRA-TV 1.13.19

Hotfix изоляции offline Player от административного интерфейса.

## Причина

До 1.13.19 Player регистрировал `/player-sw.js` с `scope: '/'`. Из-за этого Player Service Worker контролировал не только TV Player, но и административные страницы. Поскольку общий Player shell использует cache-first для модулей renderer/runtime, Scene Editor после обновления мог получить старый `/js/player/weather-bootstrap.js` из предыдущего shell cache и продолжить показывать пустой погодный элемент, хотя сервер уже работал на новой версии.

## Исправлено

- Player Service Worker теперь регистрируется только с областью `/player`.
- Админский bootstrap до импорта `/js/application.js` удаляет legacy root-scoped Player worker от старых версий.
- Если старая регистрация уже контролирует текущую страницу, выполняется однократная перезагрузка после её удаления.
- Удаляются только legacy Player shell caches; Player data/media cache сохраняется.
- Player build: `1.13.19`.
- Offline Player shell: `v35`.

## Регрессия

Browser-тест воспроизводит реальное обновление со старой root-scoped регистрацией, а не чистый браузерный профиль: устанавливает legacy worker, создаёт shell/data cache, открывает административную страницу и проверяет удаление root worker и shell cache при сохранении data cache.
