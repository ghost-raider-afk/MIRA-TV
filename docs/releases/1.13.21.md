# MIRA-TV 1.13.21

Hotfix погодного провайдера и времени выбранного города.

## Причина

Контейнер приложения подключён одновременно к внутренней сети MIRA-TV и к внешней proxy-сети. Ранее default gateway явно не задавался, поэтому исходящий запрос к Open-Meteo мог выбрать внутреннюю сеть без внешнего доступа. В таком состоянии TV мог продолжать показывать сохранённый last-known-good snapshot, а Scene Preview оставался без свежей погоды.

Отдельно timezone выбранного города теперь считается единственным источником времени для погодного pipeline.

## Исправлено

- Для сервиса `app` сеть `mira-tv-proxy` получила `gw_priority: 1`.
- Установщик гарантирует Docker Compose >= 2.33.1 для поддержки `gw_priority`.
- Выбранный timezone отправляется Open-Meteo и сохраняется в weather snapshot как authoritative timezone.
- Для Комсомольска-на-Амуре `Asia/Vladivostok` не может быть заменён timezone VPS, браузера или TV.
- Добавлены regression-тесты сетевого egress и timezone propagation.
- Player build: `1.13.21`.
- Offline Player shell: `v37`.
