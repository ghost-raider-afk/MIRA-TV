# MIRA-TV 1.14.2

Обновление массового применения настроек сцены, плотности таблицы меню и масштаба административного интерфейса.

## Изменено

- Для «Фона», «Погоды», «Картинки» и «Видео» добавлено применение настроек к нескольким выбранным мониторам.
- Массовое применение выполняется транзакционно и не оставляет частично обновлённые телевизоры при ошибке.
- Положение, размеры и связанные параметры элементов копируются через существующую общую scene-архитектуру без отдельного renderer для Preview и TV.
- В итоговом SVG таблицы немного уменьшен интервал между крупным названием позиции и мелкой строкой дополнительной информации; размеры шрифтов не уменьшались.
- В «Настройки сайта» добавлен масштаб интерфейса от 70% до 140%.
- Новая база 100% по читаемости соответствует примерно прежним 125% масштаба браузера.
- UI-scale не изменяет координаты сцены, размеры Preview/TV Runtime и не применяется к Player.
- Масштабирование сделано через общие UI-переменные без root CSS zoom, чтобы не ломать viewport, модальные окна и мобильную адаптацию.
- Плотные рабочие области Scene/Monitor/Animation сохраняют компактную геометрию.
- Добавлена миграция PostgreSQL для хранения ui_scale_percent и regression-тесты.
- Player build: 1.14.2.
- Offline Player shell: v40.

## Совместимость

Существующие сцены, привязки телевизоров, база каталога, API и данные сохраняются. Для старых установок значение масштаба интерфейса автоматически становится 100%. Preview и TV Runtime продолжают использовать общую систему рендеринга.
