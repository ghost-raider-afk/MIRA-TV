# MIRA-TV 1.14.3

Обновление Player и типографики цен таблицы.

## Player

- На экране подключения добавлено действие «Добавить ярлык MIRA-TV Player».
- В Chromium/Edge/совместимых браузерах используется штатная установка PWA.
- Для браузеров без install prompt показывается инструкция по добавлению на главный экран.
- Для Windows доступна отдельная ссылка «Скачать ярлык для Windows» с адресом текущего MIRA-TV Player.
- Добавлены manifest и PNG-иконки 192×192/512×512.
- Установленный ярлык открывает существующий /player; архитектура TV Runtime и привязка устройства не дублируются.
- Установочные ресурсы входят в offline Player shell.

## Таблица меню

- В «Типографика» добавлен независимый «Кегль цен, pt».
- Диапазон: 18–40 pt.
- Значение по умолчанию: 27 pt, что сохраняет прежний вид существующих экранов.
- Изменение работает в общем canonical SVG renderer и одинаково отображается в Preview и TV.
- Настройка применяется к основным/вторичным ценам продукции и ценам тары.

## Технически

- Player build: 1.14.3.
- Offline Player shell: v41.
- Добавлены unit/browser regression-тесты.
