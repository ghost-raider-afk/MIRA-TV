# MIRA-TV 1.14.4

Обновление роли менеджера и целевой установки TV Player.

## Менеджер

- Менеджер видит все сохранённые активные экраны активных торговых точек, включая draft / неопубликованные.
- Мини-превью и fullscreen используют существующий PlayerSceneRenderer.
- Доступ остаётся только для просмотра; административные API и изменение настроек по-прежнему запрещены.

## Player

- Установка MIRA-TV Player теперь ориентирована только на Android TV / Google TV.
- Удалён Windows .url shortcut и серверный route для него.
- Удалены Apple-specific PWA метаданные.
- На не-Android платформах интерфейс прямо сообщает, что установка предназначена для Android TV / Google TV.
- Player build: 1.14.4.
- Offline Player shell: v42.

## Проверки

- Обновлены browser/unit regression-тесты для manager draft preview и Android-only Player install.
