# MIRA-TV 1.14.5

Обновление manager-view, устойчивости PostgreSQL и индивидуального подключения телевизоров.

## Менеджер

- Убраны лишние служебные подписи и пояснения.
- Терминология приведена к «телевизор».
- Добавлено корректное русское склонение количества телевизоров.
- Исправлено масштабирование preview для published и draft экранов.
- В fullscreen добавлены крупные стрелки предыдущего/следующего ТВ и клавиши ArrowLeft / ArrowRight.
- Быстрое переключение защищено от устаревших async-ответов.

## PostgreSQL

- pg Pool обрабатывает потерю idle-соединения при рестарте БД.
- MIRA-TV больше не должен завершаться из-за необработанного pool error.
- В Docker-лог не выводится полный внутренний объект pg.Client.
- Следующий запрос использует штатное переподключение пула.

## TV-сеть

- Кнопка «Подключить» каждой карточки передаёт конкретный screen.id.
- Мастер подключения фиксируется на выбранном TV и не требует повторного выбора точки/экрана.
- Общий сценарий «Подключить ТВ» без заранее выбранного экрана сохранён.

## Runtime

- Player build: 1.14.5.
- Offline Player shell: v43.
