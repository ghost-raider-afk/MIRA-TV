# MIRA-TV 1.14.7

Hotfix перехода от авторизации телевизора к Device Session в Android TV браузерах.

## Device Session handoff

- Player явно включает credentials во всех запросах к Device API.
- После статуса `authorized` сначала проверяется `/api/device/session`, затем запускается state sync и renderer.
- Незавершённая activation сохраняется, пока HttpOnly Device Session не подтверждена.
- Повторный activation poll повторно выдаёт cookie без перепривязки телевизора.

## Диагностика

- Если браузер продолжает не принимать Device Session, сервер фиксирует `session.handoff.pending` через уже авторизованную activation.
- В TV-сети выводится «браузер не подтвердил сессию TV», поэтому дальнейшая диагностика не требует DevTools на телевизоре.

## Regression

- Добавлен Android TV browser-тест: activation уже `authorized`, Device Session отвечает 401, pairing recovery остаётся сохранённым, а handoff автоматически повторяется.
- Существующие Android TV, renderer, Last Known Good и offline-тесты сохранены.

## Runtime

- Player build: 1.14.7.
- Offline Player shell: v46.
