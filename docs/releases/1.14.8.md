# MIRA-TV 1.14.8

Релиз исправляет корневой механизм Device Session handoff для Android TV и Google TV.

## Что исправлено

- Проверен production proxy: MIRA-TV использует Traefik 3.7.12, который не переписывает Device Session `Set-Cookie`.
- Cookie остаётся `HttpOnly`, `Secure`, `SameSite=Strict`, `Path=/` с прежним TTL.
- После подтверждения QR-кода Player теперь выполняет same-origin top-level POST на endpoint завершения activation.
- Poll secret передаётся в POST body, не в URL.
- Endpoint завершения повторно использует каноническую транзакцию activation/session, устанавливает Device Session cookie и возвращает `303 /player`.
- После возврата на `/player` обычный boot подтверждает сессию и запускает Player Context, renderer и realtime.

## Regression

Добавлен browser regression для цепочки:

`authorized → POST handoff → Set-Cookie → 303 → /player → Device Session → renderer`.
