# MIRA-TV 1.18.1

Security/hotfix release после v1.18.0.

- `sharp` обновлён до 0.35.5; загрузка изображений по-прежнему структурно ограничена JPEG/PNG/WebP до передачи данных native decoder.
- Сессии администратора и менеджера переведены на серверное хранение с точечным отзывом: logout отзывает текущую сессию, а смена пароля и `session_version` инвалидируют старые сессии. После обновления существующей web-сессии потребуется один повторный вход.
- TV device sessions переведены со старого 365-дневного значения по умолчанию на 30 дней с бесшовной серверной ротацией. Существующие `device_id`, `binding_id` и `screen_id` не меняются, повторная привязка телевизоров не требуется.
- Добавлена двухслойная защита от brute force: Traefik ограничивает внешний IP-флуд на login/TV activation, а критичные login-счётчики сохраняются в PostgreSQL как HMAC-хэши и переживают рестарт приложения.
- WebSocket `/ws/device` теперь принимает браузерное соединение только с origin самого MIRA-TV с учётом proxy headers Traefik.
- В Final CI добавлена блокировка известных High/Critical production-уязвимостей; включены Dependabot и CodeQL.
- Исправлена верхняя desktop-навигация v1.18.0: выпадающее подменю больше не закрывается при прохождении курсора через визуальный 8px зазор; сценарий покрыт реальным mouse-move Playwright regression.
- Удалено неиспользуемое разрешение CSP `'wasm-unsafe-eval'` и остаточный `scripts/build-wasm.sh` от ранее удалённого motion engine.
- Player build поднят до 1.18.1, Offline Player shell — до v61, чтобы кэшированные TV Player документы гарантированно обновились без отвязки телевизоров.
