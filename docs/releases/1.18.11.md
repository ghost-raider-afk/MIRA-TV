# MIRA-TV 1.18.11

Emergency Player recovery hotfix for production TVs stuck on an old cached renderer.

- Restores deterministic Player Service Worker registration before Last Known Good restore.
- Uses a versioned Service Worker URL with `updateViaCache: none` for future releases.
- Advances Offline Player shell to v72 and makes fonts/theme artwork best-effort during install, so one optional asset cannot block updated Player JavaScript.
- Keeps Local-first ACTIVE/PREVIOUS state and atomic required scene assets unchanged.
- Restores truthful TV Network snapshots: a broken individual visual asset no longer prevents publication of the current TV frame.
- Adds Player build to boot telemetry for field diagnosis.
- No API, PostgreSQL schema, Docker volume, binding, or scene compatibility changes.
