# MIRA-TV 1.18.14

On-demand TV screenshot release.

- TV Network preview now shows the latest complete TV Player screenshot instead of treating preview as a restricted passive subset.
- Added explicit «Запросить скриншот» action; the request is delivered over the existing realtime `preview.request` channel.
- Preview dialog shows the time of the last received screenshot and the status of the manual request.
- Screenshot is displayed uncropped while preserving the canonical full TV stage capture.
- Preview GET remains a passive Last Known Good reader; only the explicit POST requests a new frame.
- No recurring screenshot loop, RAF loop, or extra TV polling is added.
- Offline Player shell advances to v75 and Player/app version to 1.18.14 so connected TVs converge on the release build.
- No PostgreSQL schema, Docker volume, scene data, or renderer architecture changes.
