# MIRA-TV 1.18.15

Manual two-column menu layout release.

- `Читаемый · 2 колонки` больше не распределяет разделы автоматически: положение каждой строки явно хранится как левая или правая колонка; раздел дополнительно можно растянуть на всю ширину.
- Редактор содержимого в двухколоночном режиме сам показывает две реальные колонки и позволяет назначать строку кнопками `← / ↔ / →` без отдельной preview-логики.
- Один большой раздел теперь можно оставить общим и вручную разложить его товары между колонками в нужном порядке.
- Тара не получила специальных зависимостей от разделов: в классическом режиме сохраняется существующая пара из двух позиций в строке, а в двухколоночном режиме каждая позиция занимает отдельную обычную строку своей колонки.
- Одноразовая migration `035-readable-manual-columns` переносит уже существующие readable-экраны в новый формат, фиксируя их прежнее автоматическое расположение как ручное. Экраны с одним разделом сохраняются слева и не требуют пересоздания.
- Preview и TV продолжают использовать общий `PlayerSceneRenderer` / `FlatMenuRenderer`; отдельный renderer не добавлен.
- Offline Player shell повышен с v75 до v76 для атомарной доставки изменённого renderer на ТВ.
- PostgreSQL schema, Docker volumes, API и Local-first lifecycle не меняются; добавляется только совместимая миграция JSON-данных существующих черновиков.
