# MIRA-TV 1.18.18

Предрелизные изменения рабочего места менеджера (CRM), доступа пользователей и адаптивного интерфейса. Включены PR #126, #127, #128. Существующие подключения телевизоров, сцены и пользовательские данные сохраняются.

## CRM и права пользователей

- Компактный каталог продукции и тары с быстрым поиском по названию и производителю, кнопкой «Изменить» и сохранением прежних размеров текста.
- Торговые точки менеджера раскрываются по требованию; предпросмотр ТВ строится через общий PlayerSceneRenderer только для открытой группы. Старые сетевые ответы не могут перезаписать актуальный кеш.
- В «Настройки → Пользователи» администратор создаёт менеджеров, изменяет пароли и назначает права на все/отдельные торговые точки и каталог. Разрешения проверяются в API, а создание пользователя/прав выполняется атомарно.
- Новые менеджеры не получают доступ к торговым точкам и каталогу до назначения. Права существующих менеджеров сохраняются при миграции.
- Универсальная «Карточка изменений» для предложения новых цен/полей каталога и свободного текстового сообщения администратору: номер, дата, автор, торговая точка, описание, статус и ответ.
- Изменения продукции и тары применяются только администратором после проверки актуальности данных. Текстовые обращения доступны без права просмотра каталога и не изменяют каталог при обработке.
- Администратор может просматривать завершённые карточки и историю решений без повторного утверждения.

## Scene Editor и мобильный интерфейс

- На ПК увеличены ширины боковых панелей, подписи слоёв, поля ввода и кнопки Scene Editor. Рабочий предпросмотр остаётся адаптивным.
- На телефоне свойства и слои открываются в широкой читаемой панели с затемнением, крупными полями и кнопкой закрытия; работают Esc и фокусная изоляция закрытой панели.
- Открытая панель свойств не закрывается при появлении экранной клавиатуры и изменении высоты viewport.
- Исправлена читаемость SVG-значков нижней мобильной навигации администратора в светлой и тёмной темах.
- На кнопке «Сканировать QR-код» вместо символа «⌗» показывается компактная SVG-иконка QR. Исправлено горизонтальное переполнение страницы подключения ТВ на узких телефонах.
- Preview и TV сохраняют общую геометрию и PlayerSceneRenderer: изменение масштаба административного UI не меняет логические размеры сцены.

## Совместимость, обновление и проверка

- Сохранены существующие данные PostgreSQL, Docker volumes, API, старые сцены, Local-first Player, ACTIVE/PREVIOUS и Last Known Good.
- Исторические миграции не удаляются. Совместимые миграции 037 (права менеджеров) и 038 (карточки CRM) сохраняют прежние учётные записи и предложения.
- Player build 1.18.18; Offline Player shell v79 сохраняет предыдущий рабочий shell v78 для отката при неуспешной загрузке. Повторно привязывать ТВ не требуется.
- Регрессионные проверки охватывают мобильные ширины 320–768 px, desktop Scene Editor, CRM/права, миграции заполненной БД, Editor → Preview → TV, Docker/Compose, Android TV и производительность Player.
- Финальный CI и production smoke (Compose, /readyz, критические Preview/Player сценарии) должны пройти до автоматической публикации GitHub Release.
