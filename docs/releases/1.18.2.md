# MIRA-TV 1.18.2

Bugfix/security release после v1.18.1.

- Исправлен первый кадр TV Player: до определения состояния подключения boot-слой гарантированно перекрывает старую или кэшированную сцену, поэтому меню больше не мелькает перед экраном подключения.
- Убрана служебная надпись `MIRA-TV Player — только Android TV`.
- Восстановлен общий realtime-канал TV за Traefik: same-origin проверка WebSocket корректно учитывает `Host` и forwarded host, поэтому статус Online и on-demand snapshot снова работают для всех телевизоров без ослабления cross-origin защиты.
- В Scene Editor клик по слою `Таблица меню` теперь только выбирает таблицу; редактор содержимого открывается исключительно кнопкой `Редактировать содержимое`.
- Исправлено создание торговой точки «по образцу»: удалены обращения к ранее удалённым animation/weather runtime API, а клон переносит актуальный канонический draft `menu + scene` без возврата retired motion/video архитектуры.
- Express обновлён до 5.3.0, `proxy-addr` до 2.0.8 для устранения Critical CVE-2026-90711; security gate не ослаблялся.
- Offline Player shell остаётся v62, чтобы исправленные Player assets доставлялись уже подключённым ТВ без перепривязки.
- API, PostgreSQL schema, Docker volumes и исторические migrations не меняются; Preview и TV продолжают использовать общий `PlayerSceneRenderer`.
