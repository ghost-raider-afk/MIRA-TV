# MIRA-TV 1.18.21

Общий выпуск системы заявок MIRA-TV: менеджер и администратор работают с шестью согласованными пресетами через единый журнал и карточки. PR #140.

- Единые пять статусов: «На рассмотрении», «На доработке», «Завершена», «Отклонено», «Ошибка». Компактный журнал; тема заявки крупно и по центру.
- Обновлена общая верхняя навигация менеджера: «Торговые точки», «Каталог», «Мои заявки», сохранён единый бренд MIRA-TV.
- Изменение цен и свойств: рассмотрение каждой строки, возврат на доработку, транзакционное применение только согласованных позиций.
- Добавление в меню и удаление из меню разделены: информационное добавление вручную; выборочное удаление только из опубликованных меню конкретных ТВ с контролем ревизий.
- Новый товар: один товар в заявке; автоматическое сохранение в каталог отдельно от ручного размещения на ТВ, защита от повторного создания.
- Обращения: обязательный ответ администратора перед «Завершить», история и возврат на доработку.
- Совместимая миграция PostgreSQL №039 сохраняет ранее созданные карточки; доступ к истории собственных заявок не зависит от доступности каталога.
- Регрессионные тесты для PostgreSQL, многопозиционных изменений, Preview/TV, мобильного интерфейса и прав доступа.

Версия приложения, установщика и Player: **1.18.21**. Offline Player shell **v82** сохраняет предыдущий рабочий shell v81. Исторические миграции, данные PostgreSQL, Docker volumes и Local-first LKG не удаляются.
