# MIRA-TV 1.18.22

Точечное обновление карточек заявок менеджера и администратора (PR #141).

- Русские, понятные названия изменяемых характеристик, без отображения внутренних технических ключей.
- Единая форма сравнения «Было → Станет» с корректным отображением рублёвых цен, цвета, фильтрации, крепости, производителя и адреса.
- Обозначение товара «Товар: название (производитель)» во всех предметных карточках и списках выбора.
- Сохранение производителя для новых заявок и совместимое отображение производителей в ранее созданных заявках без изменения исторических миграций.
- Единые компактные контурные статусы с пятью утверждёнными цветами в карточках и журнале обеих ролей.
- Регрессионные тесты UI, ролей и исторических заявок; существующие TV Runtime, сцены, PostgreSQL, Docker volumes и Local-first данные сохраняются.

Версия приложения, установщика и Player: **1.18.22**. Offline Player shell **v83** сохраняет предыдущий рабочий shell v82.
