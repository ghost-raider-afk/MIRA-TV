# MIRA-TV v1.18.23

- Торговые точки в карточках всех соответствующих заявок указаны по названию, а не по внутреннему номеру. Новые заявки фиксируют название на момент создания, старые используют совместимое чтение.
- События CRM отображаются на русском языке: завершение вручную, согласование, доработка и отказ, с подробностями по товарам, ценам и точкам.
- Scene Editor: настройка показа второй цены «1,5 л» в классическом режиме. По умолчанию выключена. Три утверждённых тематических пресета не затронуты.
- Общие данные каталога, сцены, PostgreSQL, Docker volumes и Local-first LKG сохраняются.
- Версии приложения, установщика и Player: 1.18.23. Offline Player shell v84 (предыдущий v83 сохраняется).
