# MIRA-TV v1.18.24 — персональные уведомления по заявкам

- Только CRM-заявки: новые и повторные обращения администраторам; изменения статусов — авторам заявок.
- Один Центр уведомлений в стиле Windows 11 для администратора и менеджера. В существующей панели колокольчик, рядом маленькая кнопка включения или отключения звука.
- Прочтение каждого уведомления, «Прочитать все», «Очистить все» затрагивают только учётную запись; activity_events и история заявок неизменны.
- Появление справа сверху: не больше 3 карточек одновременно (строже утверждённого предела 10), 6 секунд на карточку, пауза при наведении, серверная выдача порциями без загрузки сотен записей.
- Одобренный оригинальный короткий двухтональный звук синтезируется математически через Web Audio API, не копируется из Windows, выключен по умолчанию; звуки старых заявок не воспроизводятся.
- Приветствие при входе стало крупнее и перемещено вверх по центру.
- PostgreSQL migration 040: самостоятельное представление уведомлений поверх существующих заявок; транзакционные триггеры и LISTEN/NOTIFY с SSE, без внешних сервисов.
- Версии installer / app / Player — 1.18.24, Offline Player shell v85, previous v84 сохранён. Сам TV renderer, сцены, БД меню и LKG без изменений.

Выпуск возможен после Final CI, tree parity и production smoke.
