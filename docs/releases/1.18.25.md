# MIRA-TV v1.18.25 — Мониторинг

Новая страница **«Мониторинг»** — компактный диспетчерский центр MIRA-TV.

- «Обзор» и «Дашборд» переименованы в **«Мониторинг»** в видимой навигации, заголовке и кнопке перехода домой. Существующие внутренние маршруты и API сохраняются.
- Общая сводка TV-сети, проблемные устройства и выбранный телевизор собраны в компактную адаптивную композицию.
- Три Grafana-подобных SVG-графика FPS, нагрузки главного потока Player и памяти JS: читаемые числовые шкалы, временные деления для 1 ч/24 ч/7 д/30 д, точные подсказки и честные разрывы пропущенных замеров.
- Время работы Player показано **без графика**: продолжительность, состояние, последний полученный замер и количество замеров.
- Сохранены старые сцены, PostgreSQL, Local-first LKG и TV renderer. Новых библиотек и сетевых API нет.
- Добавлены Node и Playwright regression-тесты, включая mobile overflow и контроль масштабирования.
- Версии приложения, установщика и Player синхронизированы на **1.18.25**; Offline Player Shell **v86** сохраняет предыдущий рабочий v85.
