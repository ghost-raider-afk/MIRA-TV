# MIRA-TV v1.18.27 — надёжность CRM и журнал ошибок Traefik

Релиз объединяет [PR #157](https://github.com/ghost-raider-afk/MIRA-TV/pull/157), [PR #158](https://github.com/ghost-raider-afk/MIRA-TV/pull/158) и [PR #159](https://github.com/ghost-raider-afk/MIRA-TV/pull/159).

- Исправлена причина случайного выбора неверного товара в запросах менеджера: активная CRM-форма теперь изолирована от сохранённой карточки, отсутствующие селекторы явно требуют выбора, устаревшие ответы не подменяют каталог.
- Кнопка **«Сообщить об ошибке»** собирает допустимый контекст ошибки одним нажатием, создаёт обращение CRM и уведомляет администратора. Технические сведения доступны в карточке; повтор отправки — при ошибке связи. Секреты исключаются из диагностического отчёта.
- Traefik: уровень `WARN`; JSON access log только для HTTP 400–599, без HTTP-заголовков и query-параметров; ротация Docker логов `10m × 5`.
- **Версия приложения/Player/установщика: 1.18.27**. Player offline shell **v88** устанавливается атомарно и сохраняет v87 как предыдущую оболочку.
- Не изменяются данные PostgreSQL, привязки ТВ, старые сцены, Local-first механизм, штатная отрисовка Preview/Player и Docker volumes. Новых зависимостей нет.
- Отдельный кандидат PR #156 (диагностика связи ТВ и шрифты) остаётся за пределами этого релиза и должен получить следующий номер версии.

Автоматическая проверка перед выпуском: Node unit/contract, Docker Compose build/config, browser/visual Playwright, security. После merge: равенство Git tree, production Compose startup, `/readyz`, Preview/Player smoke и проверка опубликованного GitHub Release.

Физическое поведение на отдельных старых Android TV проверяется после установки обновления.
