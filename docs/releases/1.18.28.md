# MIRA-TV v1.18.28 — восстановление связи, диагностика и меню

Включены #155 и #156 как единый комплект (без дублирования), #163 и #164, с дополнительной защитой ротации TV cookie.

- **Стабильная связь:** HTTP-сверка при зависшем WebSocket OPEN, на событии online и при пробуждении Android TV; 15-секундный тайм-аут зависшего CONNECTING; повторное подключение с backoff.
- **Безопасная ротация:** действительные TV-сессии продлеваются через обычный player-delta. Запоздалый ответ на прежний токен не удаляет действующий HttpOnly cookie, но подтверждённая административная отвязка очищает его и локальные данные.
- **Local-first:** при недоступности сервера меню продолжает отображаться из Last Known Good; ошибочная загрузка ресурсов не уничтожает рабочую версию. Если авторизация действительно истекла, администратор может перепривязать ТВ без удаления данных браузера.
- **Администраторская диагностика:** журнал событий связи с причиной, кодом закрытия WebSocket и HTTP fallback, периоды 24 часа, 7 и 30 дней, Ping по запросу и CSV.
- **Двухколоночное меню:** логические разделы не зависят от визуального распределения, сортировка А–Я действует на целый раздел; сохранённый алфавитный порядок корректен и в классическом режиме, чередование цветов рассчитано по колонкам.
- **UI/шрифты:** маленький статический значок отсутствия связи в правом верхнем углу вместо большого баннера; DejaVu локально в Docker.
- **Версия:** app/Player/installer 1.18.28, offline shell v89 сохраняет v88.
- PostgreSQL и исторические миграции, Docker volumes, привязки ТВ, API и Preview=TV Runtime сохранены. Новых JS-зависимостей нет.

Выпуск только после объединённого Final CI, проверки Git tree, production Compose, /readyz, критических Preview/Player smoke и опубликованного GitHub Release.
