# MIRA-TV 1.18.3

Realtime hotfix после v1.18.2.

- WebSocket Player возвращён к простому критическому пути `/ws/device → Device Session → WebSocket`: `Origin`, `Host` и `X-Forwarded-*` больше не участвуют в разрешении подключения и не могут ложно отправить рабочий ТВ в Offline за Traefik.
- Без активной Device Session realtime остаётся закрыт: отсутствующая или устаревшая session cookie получает `401 Unauthorized`; привязки ТВ и ротация Device Session не меняются.
- `navigator.onLine` теперь используется только как подсказка браузера и не блокирует попытку WebSocket-соединения и не разрывает уже работающий transport на Android TV.
- Добавлены regression-тесты реального WebSocket handshake, stale/missing session, presence, `preview.request` и ложного browser-offline состояния.
- Offline Player shell обновлён с v62 до v63, чтобы исправленный realtime-клиент атомарно доставился уже подключённым ТВ без перепривязки.
- API, PostgreSQL schema, Docker volumes, Local-first Player state, renderer и Preview/TV parity не меняются.
