# MIRA-TV 1.18.7

## Что изменено

- В стиле **«Читаемый · 2 колонки»** полностью убран визуальный столбец `1,5 л`; данные второй цены остаются в каталоге и классическом стиле.
- Освободившаяся ширина отдана названию товара и крепости; `1 л` остаётся отдельной защищённой ценовой зоной.
- Карточки ТВ во всех точках больше не пересоздают кадр при 5-секундном обновлении статуса. Последний успешный кадр сохраняется как LKG и остаётся видимым даже при offline/reconnect.
- GET превью больше не инициирует capture на телевизоре. Новый кадр публикуется Player после успешного применения изменившегося контента; при подключении кадр запрашивается только если сервер ещё не имеет LKG.
- Классическая таблица уже использует ту же тёмную SVG-поверхность, что и читаемый стиль.
- Offline Player shell обновлён до v68.

Без изменений API данных каталога, PostgreSQL schema, Docker volumes и Local-first состояния.
