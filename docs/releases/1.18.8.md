# MIRA-TV 1.18.8

## Что изменено

- Во вкладке **«ТВ сеть»** статус сокращён до однозначных `Онлайн` / `Офлайн`; недостоверная строка `Контент · Черновик` убрана из карточек.
- Точки сортируются по эксплуатационному приоритету: сначала подключённые ТВ, которые раньше были онлайн и потеряли связь, затем работающие подключённые точки, затем подключённые ТВ без подтверждённой истории online, а неподключённые точки — внизу.
- Event-driven TV preview сохраняет LKG-поведение, но больше не теряет последнее изменение, если новый snapshot запрошен во время уже выполняющегося capture: запрос коалесцируется в один последующий кадр без capture-loop.
- Добавлена диагностика фактического fullscreen-режима Player. Поведение входа в fullscreen в этом релизе не менялось.
- В **Редактор сцены** добавлена кнопка **«Применить на ТВ»**. Она повторно отправляет последнее сохранённое состояние через существующий revision/realtime-механизм и не создаёт отдельный renderer.
- Исправлена доставка обновлений уже работающим ТВ: Player build синхронизирован с 1.18.8, Offline Player shell обновлён до v69, а неудачная первая активация нового shell повторяется с ограниченным backoff только пока версии действительно расходятся.
- Сохранены Local-first/LKG, ACTIVE/PREVIOUS, общий `PlayerSceneRenderer`, редкий fallback polling и отсутствие постоянных preview/fullscreen циклов.

Без изменений PostgreSQL schema, Docker volumes, каталогов данных и механики привязки ТВ.
