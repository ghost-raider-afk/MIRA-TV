# MIRA-TV 1.18.9

## Что изменено

- Исправлена первопричина, из-за которой уже подключённый Android TV мог остаться на старом закэшированном Player renderer после обновления сервера. Offline Player shell обновлён до **v70** и при реальном обновлении один раз переводит уже открытый `/player` на активный shell без фонового reload-loop.
- Благодаря этому утверждённый стиль **«Читаемый · 2 колонки»** снова гарантированно доходит до ранее застрявших ТВ: визуальная колонка `1,5 л` в этом стиле отсутствует, как и в каноническом Preview/renderer.
- Исправлен snapshot ТВ в **«ТВ сети»**: захват кратко ждёт изображения, встраивает изображения и `background-image` всех дочерних слоёв сцены, а не только корневого stage.
- Неполный кадр с недоступным визуальным asset больше не заменяет Last Known Good snapshot; предыдущий рабочий кадр сохраняется до успешного нового захвата.
- Кнопка **«Применить на ТВ»** в Scene Editor теперь корректно активируется после асинхронной загрузки выбранного монитора без ручного переключения select. Защита от отправки несохранённых изменений сохранена.
- Player build синхронизирован с **1.18.9**, Offline Player shell — **v70**. Local-first, ACTIVE/PREVIOUS, WebSocket + редкий fallback polling и event-driven preview сохранены; постоянных capture/reload циклов не добавлено.
- Release pipeline теперь имеет обязательный post-merge production smoke: после зелёного `check` на `main` поднимается production Compose, проверяется `/readyz` и критический Admin → TV → Preview/Player путь; GitHub Release публикуется только после успешного smoke.

Без изменений PostgreSQL schema, Docker volumes, привязки ТВ и исторических migrations.
