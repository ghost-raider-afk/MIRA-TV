# MIRA-TV 1.9.0

## Живое меню

- Единый менеджер «Анимации и объекты» для меню, акции, погоды, объявления, бренда, аквариума, Entity и плейлиста сцен.
- Раздельное состояние черновика и реально применённого состояния выбранного телевизора.
- Исправлена анимация акционных строк в реальном TV Player.
- Добавлены режимы анимации Entity и прямое перетаскивание объекта в Live Preview.
- Сохранена архитектура Service Worker и поддержка Range-запросов медиаконтента.

## Интерфейс

- Заголовки цен `1 л` и `1,5 л` выровнены по центру колонок, значения цен остаются выровненными вправо.
- Уплотнены панели «Погода», «Объявление», «Бренд», «Аквариум», «Объект» и «Плейлист» для рабочего окна 1600×900 без скрытия функциональных настроек.
- Для компактного режима убран только вспомогательный описательный текст; поля, переключатели и действия остаются доступными.

## Проверка выпуска

Релиз публикуется только после успешного полного workflow `check`, включая Node-тесты, Compose-проверку и браузерно-визуальные Playwright-тесты.

## Запланировано после выпуска 1.9.0

Следующий архитектурный этап зафиксирован как основа MIRA-TV 1.10.0:

- единый Scene Motion Runtime для Preview и реального TV Player вместо параллельных движков;
- один канонический Player Context и одинаковый порядок слоёв Preview/TV;
- погода как полноценный компонент scene/delta pipeline;
- атомарное применение всей сцены одной ревизией: menu motion, promotion, weather, announcement, brand, environment, Entity и Scene Playlist;
- две независимые галочки для каждого объекта: «Объект» и «Анимация»;
- удаление пользовательского глобального переключателя Motion Engine; runtime запускается автоматически только при наличии активного движения;
- возврат полной настройки Entity, включая режим анимации;
- читаемый одностраничный Playlist Studio без микроскопических вкладок и шрифтов;
- устранение белого засвета Motion Engine на уровне motion surfaces/runtime, без маскирующего overlay;
- дальнейшая оптимизация по схеме `delta -> compile changed scene -> preload -> atomic swap -> one animation runtime -> sleep when static`.

Опубликованный тег `v1.9.0` не изменяется задним числом; этот раздел фиксирует утверждённый план следующего релиза.
